# 🏃‍♂️ 모션인식 수학 올림픽 포털 🏅

> 몸을 움직이며 신나게 푸는 초등 수학 교실 — 학년별 모션인식 수학 게임을 한 곳에서.

초등학교 1~6학년 **모션인식 수학 올림픽** 웹앱들을 연결해 주는 랜딩 페이지입니다.
닌텐도 스테이지 셀렉트 화면처럼, 학생이 자기 학년 카드를 눌러 바로 게임으로 이동합니다.

## ✨ 구성

| 섹션 | 내용 |
|---|---|
| 히어로 | 글자 낙하 애니메이션 타이틀 + **라이브 데모**(펀치로 정답 격파, 스쿼트로 오답 회피) |
| 매스 핏 플로우 | 대표 종목 강조 배너 |
| 어떻게 하나요 | 카메라 켜기 → 문제 등장 → 몸으로 답하기 3단계 |
| 학년 선택 | 1~6학년 스테이지 카드 (호버 튕김 · 클릭 시 색종이) |
| 숫자 / 선생님 안내 / 푸터 | 카운트업 통계, 수업 활용 팁 |

## 🛠 기술

- 빌드 도구 없는 **정적 HTML + Tailwind CSS(CDN) + 손으로 쓴 CSS 애니메이션**
- 이미지 에셋 **0개** — 이모지와 CSS 도형만 사용
- 효과음도 파일 없이 **WebAudio**로 생성 (우측 상단 🔊 버튼으로 on/off)
- `prefers-reduced-motion` 존중, 키보드 포커스 링 지원
- 반응형: 모바일 1열 → 태블릿 2열 → 데스크톱·TV 3열

## 📁 구조

```
index.html      # 마크업
css/style.css   # 디자인 · 애니메이션
js/main.js      # 학년 데이터 + 인터랙션
vercel.json     # 배포 설정
```

## ✏️ 학년 링크 수정하기

`js/main.js` 맨 위 `GRADES` 배열 한 곳만 고치면 카드가 바뀝니다.
6학년이 완성되면 해당 항목의 `url`을 채우고 `locked`, `badge` 줄을 지우세요.

## 🚀 로컬 실행

```bash
npx serve .
```

## 👩‍🏫 수업 활용 팁

- 크롬(Chrome) 브라우저 권장
- 첫 실행 시 카메라 권한 허용 — 영상은 기기 안에서만 처리되고 저장·전송되지 않습니다
- 화면에서 2~3걸음 떨어져 상반신이 보이게 서면 인식이 잘 됩니다
- TV·전자칠판에 띄우면 학급 전체 활동으로도 좋습니다
